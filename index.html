apivuln-api-fuzzer-lite

The Sorting Depot. A spec driven fuzzer that sends random, type shaped values to the endpoints declared in a provided OpenAPI/Swagger specification (JSON), and checks declared response schemas.

The repository main.py
InputA provided OpenAPI/Swagger specification (JSON)
Requests10 per endpoint by default, set with --requests
Response checkOnly declared 200 response schemas, checked with jsonschema

Usage

./apivuln-api-fuzzer-lite [params]
ParameterWhat it does
-hShow help message and exit.
--requestsNumber of requests to send per endpoint. Defaults to 10.
--dry-runPerform a dry run without sending actual requests.

How a run is accounted

When an operation declares a 200 response schema, the response body is checked against that schema with jsonschema, and a failed check is logged as a warning. The closing line of a run counts the requests attempted, succeeded, failed, and validated. The tool's declared dependencies are faker, jsonschema, and requests.

Stated limits

  • This tool does not test for injection flaws, broken authentication, or data exposure, and it does not validate requests against the schema.
  • A run in which no request succeeded exits 1. A --dry-run run sends nothing and is exempt from that rule.
  • The usage line names no specification argument, even though the tool runs from a provided OpenAPI or Swagger specification. No flag is invented here to fill that gap.
