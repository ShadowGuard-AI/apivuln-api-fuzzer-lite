Values Sent, Schemas Checked

apivuln-api-fuzzer-lite is a spec driven fuzzer that sends random, type shaped values to the endpoints declared in a provided OpenAPI or Swagger specification in JSON. Those values are substituted for path, query, and header parameters and for request bodies.

What the lite tool does not do, stated here in the panel and not in a footnote: it does not test for injection flaws, broken authentication, or data exposure, and it does not validate requests against the schema.

The Check That Follows a Good Answer

When an operation declares a 200 response schema, the response body is checked against that schema with jsonschema, and a failed check is logged as a warning.

That conditional stays whole on this bench: no declared 200 schema, no schema check to report.

How a Run Ends

The closing line of a run counts the requests attempted, succeeded, failed, and validated.

No Success, Exit 1. Dry Run Exempt.

A run in which no request succeeded exits 1, and a --dry-run run sends nothing and is exempt from that exit. Both halves of that rule stay together here.

Getting It and Calling It

git clone https://github.com/ShadowStrikeHQ/apivuln-api-fuzzer-lite
./apivuln-api-fuzzer-lite [params]

Clone Line As Written: Wrong Account Named

The clone line above is the single install line exactly as the source writes it. It names the ShadowStrikeHQ account, while this repository lives under ShadowGuard-AI.

No Specification Argument Shown

The bracketed usage names no specification argument, even though the whole tool runs from a provided specification, so how the spec file is handed over is not spelled out in the source. No flag is invented on this page to fill that gap.

The Three Parameters

-h

Shows a help message and exits.

--requests

Sets the number of requests to send per endpoint. Defaults to 10.

--dry-run

Performs a dry run without sending actual requests.

No other parameters are listed in the source, and this bench says so rather than padding the row with likely switches for host, port, or output.
